# 光學實驗桌

凸透鏡、凹透鏡成像的網頁模擬器（手機橫放最好用；直拿會自動轉橫）。

- 拖曳燈具、光屏的底座；光屏上方的左右三角可微調 0.1 cm。
- 燈具經過 F、2F 會吸附；光屏經過焦點也會吸附。
- ① 「找到實像了」（看光屏）或 ①′ 「找到虛像了」（看透鏡）→ ② 「練習畫光路」：學生自己從標示點拖曳畫光線；「對答案」才會畫出三條主光線。
- 右下角：全螢幕（iPhone 改成「加入主畫面」說明）。

所有數字（焦距、透鏡大小、燈具、桌面長度…）在 `config.js`；光學計算在 `optics.js`；設計與定案事項在 `docs/bench-simulator.md`。
沒有任何相依套件，直接用瀏覽器開 `index.html` 即可。
